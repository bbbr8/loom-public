# Run Loom locally

Install Python 3.12+, download this repository and open a terminal in its folder.
Run `python runtime/loom.py version`, then `python runtime/loom.py describe --json`.
Create a synthetic working example with
`python runtime/loom.py research demo --directory my-synthetic-demo`.
Use a new output directory and keep generated graphs outside version control.
No server, account, API key, Docker or hosting setup is required.
