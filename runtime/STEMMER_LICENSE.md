# Porter stemmer attribution

`surd_stemmer.py` contains Vivake Gupta and Santiago Bruno's canonical Python implementation distributed by Martin Porter at https://tartarus.org/martin/PorterStemmer/python.txt . Original authorship and algorithm comments are retained. The Python 2 command-line demo was removed; Loom adds a bounded, thread-safe functional wrapper that preserves non-English tokens and identifiers.

The author distribution page https://tartarus.org/martin/PorterStemmer/ states that these encodings may be used free of charge for any purpose. Downloaded 2026-10-13. Original SHA-256: 1495b8823e12afcd06fd8795c6ee6857946be92b4033a6348cf17a191592093b
